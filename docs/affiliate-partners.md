# Affiliate partners landing page

The public `/partners` page uses the shared Alozuri layout and links to
`https://alozuricom-1c30.endorsely.com` for applications. The footer's Explore
column links to the page; primary navigation is unchanged.

Programme copy follows the supplied business requirements: 10% commission,
30-day tracking and pending period, last-click attribution, and monthly payment
of approved commissions above a $50 USD equivalent payable balance. These are
programme descriptions, not settings configured by this page. Applications,
tracking, dashboard access and commissions remain managed in Endorsely.

No published Affiliate Programme Terms & Conditions were found. A terms page
is still needed; no placeholder or broken terms link is included.

This page introduces no tracking scripts, cookies, backend or checkout changes.
The browser regression is `npm run test:e2e -- tests/e2e/partners.spec.ts`.
